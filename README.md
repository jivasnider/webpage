# Personal Website 🌐

My personal website, built to introduce myself, showcase my interests, and share my work and projects.

## Live Website

**[Visit My Website](https://jivasnider.github.io/webpage/)**

## Overview

This website serves as my personal space on the web, bringing together my background, interests, experiences, and projects in one place.

It is designed to provide an overview of who I am, what I do, and what I am passionate about.

## Features

- Personal introduction and background
- Visual content and personal photography
- Personal interests and hobbies
- Engineering and technical interests
- Project and portfolio showcase
- Simple and accessible website design

## Technologies Used

- **HTML5** – Website structure and content
- **CSS3** – Styling, layout, and visual design

## Getting Started

To run the website locally:

1. Clone the repository:

```bash
git clone https://github.com/jivasnider/webpage.git
```

2. Navigate to the project directory:

```bash
cd webpage
```

3. Open `index.html` in your browser.

No additional dependencies are required.

## Deployment

The website is hosted using **GitHub Pages**.
